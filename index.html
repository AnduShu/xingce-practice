支持 JSON 文件。每题字段：id,module,type,year,province,difficulty,stem,options,answer,explanation。options 为字符串数组，answer 为 A/B/C/D 等选项字母。

网站会自动读取仓库根目录的 question_bank.json 公共题库。这里手动导入的文件只对当前浏览器临时生效；若要让所有访客长期看到更新，请将新 JSON 文件提交到 GitHub 仓库根目录并覆盖 question_bank.json。系统按题干+选项指纹去重。请只导入你有权使用的题目。

公共题库文件 question_bank.json 为原创模拟练习题，不是历年官方真题。浏览器答题进度保存在本机，不会因更新题库而自动同步到其他设备。
